# ChatterBoxTTS
ChatterBoxTTS GUI for those who want to clone their own voice or other people's voices.

<img width="1182" height="912" alt="image" src="https://github.com/user-attachments/assets/659b535e-9b38-4d1b-8717-fac3025b6066" />

Drop the voice that you want to clone as per the instructions in the README.txt then start generating cool stuff.

This TTS is the best at cloning so far. Yeah there's bigger ones like MeloTTS, Qwen, CosyVoice or IndexTTS, but those ones require a beefy system.

For chatterbox, I got it running and my system is very weak. 

I use an old pc from 2011 era, i5 2310 and radeon r5 430, which are absolutely outdated, but outdated to AI bros only...🤣

This PC is perfect for anything, ollama and Text to Speech AI models, it handles both. 

So, for those who have the bigger system, you'll find the 4 TTS tools I uplaoded here very useful, and balabolka might loose its place. 

If you want balabolka voices, inbox me at gmail. I was given almost all IVONA voices and some other balabolka ones for free. 

But I replaced them once I started using PiperTTS and Supertonic, coz those are the ones that run fastest on my current PC. 

Enjoy!🚀👊
